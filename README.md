# カベミル

**壁とコンセントの位置がミルミルわかる無料展開図エディタ**

部屋の壁を正面から見た図(壁面図)をブラウザ上で作り、コンセント・スイッチ・照明の記号を高さ付きで書き込んで、画像として家づくりの打ち合わせに持って行ける無料Webツールです。

- 公開URL: https://kabemiru.com (準備中)
- 登録不要・無料。入力データはお使いのブラウザ内にのみ保存され、サーバーには送信されません

## 免責・非公式であることについて

- カベミルは、家づくり中の施主が個人で運営する**非公式**ツールです。特定の住宅会社とは一切関係ありません
- 本ツールで作る図は**検討用の概略図**です。正式な寸法・仕様は、必ず図面と担当者へのご確認でご判断ください
- 記載の会社名・商品名(一条工務店、HUGme 等)は各社の商標または登録商標です
- 詳細は [免責事項・プライバシーポリシー](./policy.html) をご覧ください
